# Marca Hijos Prósperos en la app

## Colores

| Color | Código | Uso |
| --- | --- | --- |
| Azul marino | `#170B5B` | Textos, fondos oscuros, barra superior |
| Azul cielo | `#2D8EBB` | La isla, detalles, enlaces |
| Naranja | `#ED480F` | Botones principales, borde de Dinerito |
| Oro | `#FFB81C` | Monedas, Dinerito y premios |
| Blanco | `#FFFFFF` | Fondo de las misiones |

Los tres primeros salen del logo oficial. El oro se agregó para las monedas.

## Letras

- **Fredoka** para títulos y botones: redondeada y gruesa, como el logo.
- **Nunito** para el texto.

## Dinerito

Moneda dorada con borde naranja, gorra azul cielo, brazos y piernas azul marino. Tiene 4 poses: feliz, celebrando, pensando y saludando. En la bienvenida está animado: flota, parpadea, saluda y salta al tocarlo. Está dibujado en código en `js/dinerito.js`, así que se ve nítido en cualquier pantalla. Si existe un dibujo oficial de Dinerito, se puede reemplazar ahí.
